DESLIGA Áudio — pacote Vercel

1. Importe/deploy este diretório na Vercel.
2. Configure a variável de ambiente ELEVENLABS_API_KEY como Sensitive.
3. Faça novo deploy após configurar a variável.
4. Abra o site, escolha uma faixa e uma voz, e gere o MP3.

A chave nunca deve ser colocada no index.html ou em qualquer código do navegador.
